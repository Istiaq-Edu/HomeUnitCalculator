[Audit index](README.md)  
Last updated: 2026-11-12  
Status: source-discovered inventory with ongoing remediation updates; RUN-01's global card-handler replacement has been removed and locally verified.

## Interpretation and scope

This inventory covers application-defined temporal state: flags, references, timers, widget values, deferred notifications, worker handles, caches, and persisted checkpoints. It groups closely coupled transitions into 34 families; it is not proof of every runtime interleaving or Qt/SDK internal state.

Names below summarize the current implementation. They are not claims that the application already has corresponding explicit enums or state classes. Unless persistence is mentioned, state is in memory and normally resets on restart. A missing guard means the inspected transition path lacks it, not that every resulting failure has been reproduced.

Classification: **O** orchestration; **D** domain; **V** view; **R** resource lifecycle.

## Sequential operations that are not separate retained machines

- Save/export orchestration performs dialogs and synchronous writes; it reads displayed results without a freshness guard. [HomeUnitCalculator.py:1465](../../../src/core/HomeUnitCalculator.py#L1465).
- Monthly persistence has durable partial outcomes but no retained operation journal. [supabase_manager.py:236](../../../src/core/supabase_manager.py#L236).
- Calculation deletion removes rooms then main without a shared transaction. [supabase_manager.py:1016](../../../src/core/supabase_manager.py#L1016).
- History cloud download is fetch, save dialog, and synchronous export, not an asynchronous download machine. [history_tab.py:4923](../../../src/ui/tabs/history_tab.py#L4923).
- API wrappers, validation, styling, error classification, and pure month arithmetic are not FSMs merely because they branch.
- FlowLayout contains cache-related fields without a demonstrated transition to valid cached state. [flow_layout.py:31](../../../src/ui/flow_layout.py#L31).
- The legacy manual configuration tab is not the current cloud navigation route.

## Highest-risk interactions

1. **Connection x requests x cache:** old OAuth signals, cached managers, monitor snapshots, and worker results can outlive their connection generation and publish into a new project context.
2. **Selection x worker lane:** new filter/year/source intent can be lost while an old worker is running; later callback publication can contradict visible controls.
3. **Draft x result x save:** labels retain apparently valid values after edits, and persistence has no revision check.
4. **Edit ownership x remote refresh:** a set cannot represent overlapping owners; modal protection does not cover the persistent form draft.
5. **Main sync x room sync x checkpoint:** one lane advances the cursor another reads, while cache publication is not atomic.
6. **Close x image worker x widget lifetime:** requesting interruption or dismissing a dialog does not prove blocking work is finished.
7. **Partial persistence x retry:** a successful destination can be repeated because the UI does not retain its receipt or identity.

## Minimal explicit state worth introducing

- Connection attempt identity, generation, and terminal/cancellation acknowledgement.
- Immutable request context, latest requested parameters, and one pending replacement.
- Draft/result revisions and validity.
- Owner-token edit sessions, not domain-only booleans/sets.
- Per-project, independently owned synchronization checkpoints and complete snapshot receipts.
- Per-destination save outcomes and retry receipts.

Keep simple hover/collapse flags, Qt animation states, and the existing token-guarded undo approach. No general FSM framework is warranted for every helper.

## Verification and maintenance

The state specialist performed read-only source investigation, not runtime execution. Reproduced failures are identified in the linked finding registers; other missing guards require the controlled tests in [verification and roadmap](verification-and-roadmap.md#acceptance-tests).

When implementation changes a machine, update its transitions and invariants here, link the corresponding finding, and record the exact verification. Do not mark lifecycle cancellation complete solely because a stop method was called.
